# Random Cleaning Duty

사무실 청소 당번을 균등하게 자동 배정하는 웹 앱입니다.

## 운영 방식

- 하루에 **2명**이 함께 청소를 담당합니다.
- 일요일 및 공휴일은 배정에서 제외합니다.
- 1인당 담당 횟수는 격월로 **1번 → 2번 → 1번 → 2번** 순으로 번갈아 배정합니다.
- 표의 **앞부분 / 뒷부분** 담당 순서도 사람마다 번갈아 배정합니다.

## 배정 원칙

1. 하루에 2명 배정
2. 일요일 및 공휴일은 담당 배정 제외
3. 담당 횟수는 모든 인원이 균등하게 배정
4. 사람마다 앞부분/뒷부분 순서를 번갈아 담당
5. 격월 운영 시 개인별 1번, 2번 담당을 번갈아 적용

## 기능

| 기능 | 설명 |
|------|------|
| 직원 관리 | 입사자 추가, 퇴사자 삭제 |
| 엑셀 불러오기 | 초기 직원 명단을 엑셀에서 가져오기 |
| 자동 배정 | 배정 버튼으로 당번표 자동 작성 |
| 명단 수정 | 배정된 명단을 직접 수정 가능 |
| 언어 전환 | 한국어 ↔ 중국어 토글 |

## 당번 역할

매일 당번은 2명입니다.

| 위치 | 담당 | 업무 |
|------|------|------|
| 왼쪽 (앞부분) | 주방 | 음식물 쓰레기통 청소, 정수기 주변 닦기 |
| 오른쪽 (뒷부분) | 화장실 | 변기 시트 클리너 확인·보충, 화장실 휴지 확인·보충 |

당일 청소가 어려운 경우, 미리 다른 분과 상의하여 날짜를 변경해 주세요.

## 당번표 형식

| 날짜 | 앞부분 담당 | 뒷부분 담당 | 비고 |
|------|-------------|-------------|------|
| … | … | … | … |

## 시작하기

1. `index.html`을 브라우저에서 엽니다.
2. 엑셀 파일로 직원 명단을 불러오거나, 직접 직원을 추가합니다.
3. **배정** 버튼을 눌러 당번표를 생성합니다.
4. 필요 시 배정된 명단을 수정합니다.

## 참고

- 상세 요구사항: `random cleaning duty.txt`
